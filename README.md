# Girl of NevaeH — Roblox (separate from the phone arcade)

This pack is **only** the Roblox experience. The original Girl of NevaeH website/app is a different project and is not in this file.

## On iPhone

1. Save this zip to **Files**.
2. Tap it to unzip.
3. AirDrop or save the folder to a Mac/PC that has **Roblox Studio**.
   iPhone cannot open Studio or publish a place. The Roblox app only plays games that are already published.

## On a computer (Roblox Studio)

1. Open **Roblox Studio**.
2. **File → Open from File** → `GirlOfNevaeh.rbxlx`.
3. Press **Play**. Walk onto a neon pad. **H** returns to the hub.
4. Creator Hub → upload `GameIcon.png` as the experience icon and `Thumbnail.png` as the thumbnail.
5. Name the experience **Girl of NevaeH** → **File → Publish to Roblox**.
   Public experiences need ID verification.
